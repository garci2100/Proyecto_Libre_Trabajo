# Proyecto

## Estructura del proyecto

-   **main.py**: contiene el menú y las interacciones con el usuario.
-   **logica.py**: contiene las funciones que procesan los datos.
-   **datos_juegos.json**: guarda la colección para que no se pierda al
    cerrar el programa.
-   **requirements.txt**: contiene la librería externa necesaria para la
    API.
